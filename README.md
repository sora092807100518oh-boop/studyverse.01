# StudyVerse

StudyVerse は、PIN と教室コードを入口にした、スマートフォン優先の学習アプリです。独自に実装した宇宙テーマの操作空間に、単語帳、カード練習、テスト、StudyJournal、タイマー、学習カレンダー、ミッション、教室管理の導線を備えます。既存サービスの利用者情報、ロゴ、画像、秘密情報は取り込みません。

## 起動方法

依存関係をインストールした後、開発サーバーを起動します。

```bash
pnpm install
pnpm dev
```

型検査、単体テスト、プロダクションビルドは以下で実行できます。

```bash
pnpm check
pnpm test
pnpm build
```

## 初期操作

初期画面では、4桁のPINと教室コードを入力します。ローカルの体験モードでは、任意の4桁と教室コードで学習画面に入れます。教室コードのカメラ読取ボタンは、対応端末でのQR連携を想定した入口であり、現段階ではサンプルコードを入力します。

| 領域 | 現在操作できること | データ連携の状態 |
| --- | --- | --- |
| ホーム | 学習概要、カレンダー詳細、タイマー、各学習画面への遷移 | タイマーは画面内で継続します。 |
| 単語帳 | 英単語／漢字の切替、単語帳作成、単語追加、発音 | 画面上の教材編集は即時反映されます。 |
| 単語カード | 練習、フリップ、覚えた／復習、入力テスト、結果 | 操作フローを実装済みです。 |
| StudyJournal | 科目・難易度選択、通常生成の待機状態、読解・ミニテスト表示 | 本番AI・ニュース接続は次項の設定が必要です。 |
| 管理画面 | 教室、利用者、教材、配信、予定の管理導線 | 役割に応じたサーバー側権限制御を追加する前提です。 |

## データモデルとデータ分離

データベースには、`classrooms`、`studentProfiles`、`wordbooks`、`vocabularyWords`、`studyRecords`、`focusSessions` を用意しています。教材は本人限定、教室公開、全体公開の範囲を持ち、取得時に本人・教室・公開範囲を判定する構成です。`studentProfiles` の一意条件は **教室IDとPINハッシュの組み合わせ**であり、同じPINでも別教室では別の学習者として扱えます。

マイグレーションを新規環境に反映する場合は、`drizzle/schema.ts` から SQL を生成し、内容を確認してからDBに適用してください。

```bash
pnpm drizzle-kit generate
```

## 環境変数と外部連携

プラットフォームが自動注入する認証、DB、ストレージ、AI向けの環境変数はコードに直接記録しません。本番で次の機能を有効にする際は、サーバー側の連携層から利用してください。

| 連携 | 必要になる設定 | 接続前の挙動 |
| --- | --- | --- |
| StudyJournal生成 | サーバー側AI呼び出し | 記事生成の準備・再試行案内を表示します。 |
| 今日の記事 | 当日公開ニュースを取得できる信頼済みソース | 当日の記事を取得できない旨を表示し、古い記事へ自動代替しません。 |
| 漢字のAI採点 | 画像入力対応のAI連携 | 手書き答案の確認フローを保ち、再試行を案内します。 |
| モンスター画像 | S3互換ストレージ | 画像登録導線を表示し、ファイル本体はDBに保存しません。 |
| QR読取 | ブラウザのカメラ権限 | 権限を求め、拒否時は手入力を維持します。 |

AI呼び出しは必ずサーバー側から実行し、構造化出力を検証してから記事・問題・採点結果に反映してください。外部連携が失敗した場合は、内部エラーをそのまま表示せず、日本語の再試行・設定案内に変換します。

## 管理者の初期設定

最初に全体管理者が教室コードと教室名を作成し、先生を教室へ関連付けます。先生は自教室の教材、予定、お知らせを管理し、生徒は本人の学習と所属教室で公開された教材だけを利用します。全体管理者のみが教室を横断して閲覧・絞り込みできます。

## 未確定事項

本番のPINセッション発行、ログイン試行のレート制限、QRコードの実カメラ読取、ニュース提供元の選定、StudyJournal・漢字採点のAI品質基準、モンスター画像の登録UIは、サービス接続先と運用ポリシーの確定後に拡張します。これらは画面の前提を壊さず追加できるよう、データモデルとエラー導線を先に整えています。
